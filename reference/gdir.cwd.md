# Returns the current working directory in Genomic Database

Returns the absolute path of the current working directory in Genomic
Database.

## Usage

``` r
gdir.cwd()
```

## Value

A character string of the path.

## Details

This function returns the absolute path of the current working directory
in Genomic Database (not to be confused with shell's current working
directory).
